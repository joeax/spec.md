# Contributing

Thanks for your interest in improving SPEC.md.

## Before You Start

- Read the [README](README.md) and existing docs.
- Search existing [issues](../../issues) before opening a new one.
- Keep changes focused and scoped to one topic.

## Ways to Contribute

- Report bugs
- Improve documentation
- Suggest improvements

## Feature Requests and Breaking Changes

- Please open an issue first for any feature idea.
- Suggestions that may introduce breaking changes should be discussed in an issue before any implementation work.
- Pull requests for new features are not being accepted yet.

## Pull Request Guidelines

- Open a pull request only for bug fixes and documentation updates.
- Link the related issue in the pull request description.
- Keep pull requests small and reviewable.
- Update documentation when behavior changes.

## Commit Message Conventions

Use clear, imperative commit messages, for example:

- `fix: handle invalid schema path`
- `docs: clarify spec sync behavior`

## Questions

If you are unsure whether a change is in scope, open an issue first.
