# Simple CRM Frontend

A lightweight CRM frontend for small businesses and teams that need a simple way to manage contacts. There is no backend yet -- contact data is managed through a mocked API layer and persisted in browser local storage until a real backend is introduced.

## Features

- Manage a list of contacts with core profile details such as name, email, phone, and company.
- Create, view, update, and delete contacts.
- Search and filter contacts.
- Preserve contact data locally in the browser so it remains available after refreshes.
